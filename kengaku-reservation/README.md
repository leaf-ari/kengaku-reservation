# 見学予約システム - セットアップガイド

**株式会社リーフ 採用向け見学予約ツール**

採用担当者がスマホからその場で見学予約を取れるWebフォームです。
Google Apps Script と Google スプレッドシートを使い、無料で運用できます。

## 1. Googleスプレッドシートを作る

1. ブラウザで [Google スプレッドシート](https://sheets.google.com) を開く
2. 左上の **「＋ 空白」** をクリックして新しいシートを作る
3. タイトルを「見学予約管理」などわかりやすい名前にする（任意）

> **💡 ポイント**  
> 列の見出しやシート名は、Google Apps Script が初回予約時に自動で作ってくれます。  
> 何も入力しなくて大丈夫です。

---

## 2. Google Apps Scriptを設定する

### 2-1. スクリプトエディタを開く

1. 作成したスプレッドシートを開いた状態で、上のメニューから  
   **「拡張機能」→「Apps Script」** をクリック
2. スクリプトエディタが別タブで開く

### 2-2. コードを貼り付ける

1. エディタの左側に `コード.gs` というファイルが表示されている
2. 中に最初から書いてあるコードを **すべて消す**
3. このリポジトリの **`code.gs`** の中身を **まるごとコピーして貼り付ける**
4. 上のフロッピーアイコン（または `Ctrl+S`）で **保存** する

### 2-3. 初期動作を確認する（任意）

1. 上部の関数選択メニューで `testSetup` を選ぶ
2. **「実行」** ボタン（▶）をクリック
3. 「承認が必要です」と出たら手順に従って許可する
4. 下部のログに「セットアップ完了!」と出れば OK

## 3. ウェブアプリとしてデプロイする

> ⚠️ **この手順が最も重要です。必ず「全員」に公開してください。**

1. スクリプトエディタの右上にある **「デプロイ」** ボタンをクリック
2. **「新しいデプロイ」** を選択
3. 歯車アイコン ⚙️ をクリックし **「ウェブアプリ」** を選択
4. 以下のように設定する：

   | 項目 | 設定値 |
   |------|--------|
   | 説明 | 見学予約システム（任意） |
   | 次のユーザーとして実行 | **自分（あなたのGoogleアカウント）** |
   | アクセスできるユーザー | **全員** |

5. **「デプロイ」** をクリック
6. 「アクセスを承認」が出たら：
   - 「アクセスを承認」をクリック
   - Googleアカウントを選択
   - 「このアプリはGoogleで確認されていません」と出たら **「詳細」→「（アプリ名）に移動」** をクリック
   - **「許可」** をクリック
7. **「ウェブアプリのURL」** が表示される ← **このURLをコピーしてください！**

```
例: https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxx/exec
```

> 💡 URLは後でも確認できます：「デプロイ」→「デプロイを管理」から確認できます。

## 4. script.jsにURLを貼り付ける

1. このリポジトリの `script.js` をテキストエディタで開く
2. 先頭付近にある以下の行を見つける：

```javascript
const GAS_URL = 'YOUR_GAS_URL_HERE';
```

3. `YOUR_GAS_URL_HERE` の部分を、コピーしたURLに **まるごと置き換える**

```javascript
// ↓ こんな感じになればOK
const GAS_URL = 'https://script.google.com/macros/s/AKfycbxxxxxxxxxxxxxx/exec';
```

4. ファイルを保存する

## 5. GitHubにアップしてGitHub Pagesで公開する

### 5-1. GitHubにリポジトリを作る

1. [GitHub](https://github.com) にログイン（アカウントがない場合は無料で作成）
2. 右上の **「＋」→「New repository」** をクリック
3. 以下のように設定する：
   - Repository name: `kengaku-reservation`（任意）
   - **Public** を選択（GitHub Pages は Public リポジトリなら無料）
4. **「Create repository」** をクリック

### 5-2. ファイルをアップロードする

**方法A：ブラウザからアップロード（初心者向け）**

1. 作ったリポジトリのページを開く
2. **「uploading an existing file」** をクリック
3. 以下の4ファイルをドラッグ＆ドロップ：
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
4. 下の **「Commit changes」** をクリック

**方法B：git コマンドを使う（慣れている方向け）**

```bash
git init
git add index.html style.css script.js README.md
git commit -m "初回コミット"
git branch -M main
git remote add origin https://github.com/あなたのユーザー名/kengaku-reservation.git
git push -u origin main
```

### 5-3. GitHub Pages を有効にする

1. リポジトリページの **「Settings」** タブをクリック
2. 左サイドバーの **「Pages」** をクリック
3. 「Source」の **「Deploy from a branch」** を選択
4. Branch を **`main`** / フォルダを **`/ (root)`** に設定
5. **「Save」** をクリック
6. しばらく待つと（1〜3分）、以下のような公開URLが表示される：

```
https://あなたのユーザー名.github.io/kengaku-reservation/
```

> 💡 URLが表示されるまで数分かかる場合があります。表示されない場合はページを更新してみてください。

## 6. 採用担当者に共有する

### 共有するURL
```
https://あなたのユーザー名.github.io/kengaku-reservation/
```

このURLをLINE・Slack・メールなどで採用チームに共有してください。

### 使い方（採用担当者向け）

1. スマホのブラウザでURLを開く
2. **学生情報**（氏名・学校名・電話番号・メールアドレス）を入力
3. **希望日** をタップして選択 → 空き枠が自動で表示される
4. **希望時間** をタップして選択（満席の枠は選べない）
5. **担当者名** を入力
6. **「予約を確定する」** ボタンをタップ
7. 「予約が完了しました」と表示されれば完了

### スプレッドシートで予約を確認する

1. Googleスプレッドシートを開く
2. 「予約一覧」シートに予約データが追加されている
3. スプレッドシートは採用チームのメンバーと共有できます（「共有」ボタンから）

## 7. スプレッドシートの列の説明

初回の予約登録時に、スプレッドシートに以下の列が自動で作成されます。

| 列 | 項目名 | 内容 |
|----|--------|------|
| A | 受付日時 | 予約登録された日時（自動） |
| B | 学生氏名 | 学生の氏名 |
| C | 学校名 | 大学・学部など |
| D | 電話番号 | 学生の電話番号 |
| E | メールアドレス | 学生のメールアドレス |
| F | 希望日 | 見学希望日（YYYY-MM-DD形式） |
| G | 希望時間 | 開始時間（HH:MM形式） |
| H | 担当者名 | 予約を取った採用担当者名 |
| I | メモ | 特記事項 |
| J | ステータス | 「予約済み」（将来のキャンセル機能用） |

## 8. よくあるトラブル

### Q. 予約を送信しても何も起きない

**A.**
- `script.js` の `GAS_URL` が正しく設定されているか確認する
- ブラウザのコンソール（F12キー→「コンソール」タブ）でエラーメッセージを確認する
- GASのデプロイ設定で「アクセスできるユーザー」が **「全員」** になっているか確認する

### Q. 「アクセスが拒否されました」のようなエラーが出る

**A.**
GASのデプロイ設定を確認してください。
1. 「デプロイ」→「デプロイを管理」をクリック
2. ✏️ 編集アイコンをクリック
3. 「アクセスできるユーザー」が **「全員」** になっているか確認
4. 変更した場合は「バージョン」を **「新しいバージョン」** に変えてから「デプロイ」をクリック

### Q. コードを変更したのに反映されない

**A.**
GASのコードを変更した場合は **再デプロイが必要** です。
1. 「デプロイ」→「デプロイを管理」をクリック
2. ✏️ 編集アイコンをクリック
3. バージョンを **「新しいバージョン」** に変更して「デプロイ」をクリック

### Q. 空き枠が表示されない（「通信エラー」と出る）

**A.**
- スマホの通信環境を確認する
- GASのURLが正しいか確認する（`YOUR_GAS_URL_HERE` のままになっていないか）
- GASのデプロイ設定が「全員」になっているか確認する

### Q. スプレッドシートに「予約一覧」シートが作られない

**A.**
初回の予約送信時に自動で作成されます。  
事前に確認したい場合は、GASエディタで `testSetup` 関数を手動実行してください。
